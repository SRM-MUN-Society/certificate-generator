# CertiGen Pro - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### 1. Upload Template (30 seconds)

```
1. Click "Upload Template (Image or PDF)"
2. Select your certificate background:
   - Images: PNG, JPG, JPEG, GIF, WEBP
   - PDF: First page auto-converts to image (5-10 sec)
3. Wait for template to load
```

**Tip:** Use high-resolution files (1920×1080px or higher) for best results. PDF templates are automatically converted to high-quality images.

---

### 2. Add Text Elements (1 minute)

**Default Elements Included:**
- ✅ Certificate Title
- ✅ Recipient Name (`{name}`)
- ✅ Course Name (`{course}`)
- ✅ Date (`{date}`)

**To Customize:**
```
1. Click text element in preview or list
2. Switch to "Typography" tab
3. Edit text, font, color, size
4. Drag element to reposition
```

**Dynamic Variables:**
- `{name}` → Recipient name
- `{course}` → Course/program
- `{date}` → Issue date
- `{email}` → Recipient email

---

### 3. Add Recipients (1 minute)

**Option A: Import CSV**
```
1. Go to "Recipients" tab
2. Click "Import CSV/Excel"
3. Select file with columns: name, email, course, date
```

**Option B: Manual Entry**
```
1. Fill in the form
2. Click "Add Recipient"
3. Repeat as needed
```

**CSV Format:**
```csv
name,email,course,date
"John Doe","john@example.com","Web Development","October 8, 2026"
```

---

### 4. Generate Certificates (2 minutes)

```
1. Go to "Delivery" tab
2. Choose format: PDF or PNG
3. Choose mode: Download ZIP or Email
4. Click "Generate & Download"
5. Wait for processing
6. Download ZIP file
```

**That's it! Your certificates are ready! 🎉**

## 🎨 Design Tips

### Text Positioning:
- **Center alignment:** X = 50%
- **Left edge:** X = 10-15%
- **Right edge:** X = 85-90%
- **Top:** Y = 10-20%
- **Bottom:** Y = 80-90%

### Font Sizes:
- **Title:** 40-60px
- **Name:** 50-70px
- **Body text:** 16-24px
- **Date/small text:** 14-18px

### Font Pairings:
- **Classic:** Cinzel + Cormorant Garamond
- **Elegant:** Playfair Display + Great Vibes
- **Modern:** Montserrat + Inter
- **Formal:** Cinzel + Alex Brush

2. Generate App Password: https://myaccount.google.com/apppasswords

## 🆘 Troubleshooting

### Template won't upload?
- Check file is an image (PNG, JPG)
- Try smaller file (<10MB)
- Refresh page and try again

### Text not showing?
- Check if position is on screen (0-100%)
- Check if color contrasts with background
- Increase font size

### Export failed?
- Ensure template is uploaded
- Ensure recipients list is not empty
- Try with just 1-2 recipients first

### Email not sending?
- Double-check credentials
- Use app password, not regular password
- Check recipient email addresses

2. **Save your template:** Use "Save Config" after designing
3. **Check recipient data:** Verify names and emails
4. **Use high-res images:** 1920×1080px minimum
